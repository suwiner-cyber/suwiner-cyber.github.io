使用方式

1. 在仓库的 xiaoxiaoshuo/config/sources.json 中加入你有权采集/再分发的小说站并设置 authorized: true。

2. Actions 会自动运行；也可以手动运行 小小说中央书库 · 定时更新。

3. 将上面的 booksource.json 导入小小说 APP。此 GitHub Pages 版本是静态托管，不能提供真正的服务端 Token 保密鉴权。
